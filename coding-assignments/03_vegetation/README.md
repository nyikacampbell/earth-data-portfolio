# Coding Challenge 3: Water Rights in the Gila River

In 2004, the Akimel O’otham and Tohono O’odham tribes won a water rights settlement in the US Supreme Court. Using satellite imagery, you will examine the effects of irrigation water on the local vegetation.

## Challenge Overview
To complete this assignment on your computer:

1. Fork the repository and go to your version of the repo. 
2. Clone your version of the repository using GitHub Desktop. 
3. Open the project folder in VS Code. 
4. Commit and sync your local changes to update the code in your GitHub repository. 
5. Submit the url to your GitHub repository for the assignment on Canvas.  

For the portfolio assignment, you will need to do the following additional steps:  

6. Create a new notebook in your portfolio repository. 
7. Concisely duplicate your analysis for a different location/study area of your choosing. You will need to use the code in 06-portfolio-get-ndvi-data.ipynb to acquire NDVI data for this new location. Only include the code needed to generate the main plots you make. You do not need to include all the code from the original assignment notebooks if it isn't relevant. 
8. Write a portfolio post explaining your research questions, methods, results, and interpretation. Add your interactive plot to the post, with a title and description of the plot.  
9. Upload the post to your data science portfolio webpage to show off your work!
