# Coding Challenge 2: Veery Migration
The Veery thrush (*Catharus fuscescens*) migrates each year between nesting sites in North America and South America. Veeries are small birds, and encountering a hurricane during their migration would be disasterous. However, ornithologist Christopher Heckscher has found in tracking their migration that their breeding patterns and migration timing can predicting the severity of hurricane season as accurately as meterological models! You can read more about this finding [here](https://doi.org/10.1038/s41598-018-28302-3).
